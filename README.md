# 복지인사이트 Case-IN

노인 초기면접·선정기준 관리를 위한 브라우저 기반 앱입니다. 데이터는 사용자의 브라우저 IndexedDB(`welfare_insight_intake_v1`)에만 저장됩니다.

## Case-IN Voice (AI 사전 상담)

`🎙 AI 사전상담` 버튼으로 실행되는 음성 대화형 사전 상담 보조 기능입니다. **정식 초기면접을 대신하는 것이 아니라**, 담당 사회복지사가 방문·상담을 나가기 전에 어르신의 생활·정서·관계 등을 미리 파악할 수 있도록 돕는 도구입니다.

- 시작 전에 **어르신 성함을 먼저 등록**합니다(신규 사례일 때만; 이미 열려있는 사례에서 시작하면 그 사례 이름을 그대로 씁니다). 이 이름은 Case-IN 목록에 사례를 등록하는 용도로만 쓰이며 **AI에게는 전달되지 않습니다**.
- AI는 곧바로 초기면접성 질문을 던지지 않고, 먼저 안부 인사와 가벼운 대화로 라포를 형성한 뒤 자연스럽게 본론으로 넘어갑니다.
- 대상자와 AI가 음성으로 편하게 대화하며 생활상황, 건강, 정서, 관계, 어려움, 희망 지원, 강점 등을 파악합니다. **주민등록번호·정확한 주소·전화번호·계좌번호·성함 등 직접적인 개인정보는 AI가 묻지 않고, 전달되지도 않습니다.**
- AI가 파악한 내용은 화면에서 실시간으로 확인/추가확인 상태로 표시되며, 담당 사회복지사가 방문 전 참고할 "사전 상담 브리핑"(주요 호소내용, 욕구, 강점, 방문 시 살펴볼 점 등)으로 정리됩니다.
- **AI는 결과를 바로 저장하지 않습니다.** 사전상담 종료 후 사회복지사가 검토·수정하고, 반영할 항목만 직접 체크(기본은 모두 미체크)한 뒤 `사회복지사 확인 및 저장`을 눌러야 Case-IN 기록에 참고자료로 반영됩니다.
- 아바타는 Case-IN 로고 원본(`avatar/logo-full.png`)을 그대로 사용해 인위적인 배경 없이 로고 자체가 돋보이게 하고, 뒤쪽 후광이 항상 은은하게 회전합니다. 마우스/터치로 움직이면 3D로 기울어지고 하이라이트가 따라오는 인터랙티브 효과가 있으며, 상태(듣는 중/생각 중/말하는 중 등)에 따라 후광 색상·속도가 바뀝니다. 실제 사람 사진이 아니므로 오인 위험이 없습니다.
- 구현 파일: `voice/*.js`, `voice/voice-styles.css` (프론트엔드), `api/voice-session.js`, `api/interview-summary.js` (서버리스, OpenAI 키 보관)

## 원격 사전 상담 (링크 공유)

사회복지사가 화면에서 **🔗 사전상담 링크 만들기**를 누르면 (신규 사례일 때만) 어르신 성함을 먼저 입력하고, 사전 상담 전용 링크(`pre-consult.html?t=...`)가 만들어집니다. 이 링크를 문자·카카오톡·이메일 등 기관에서 쓰는 방법으로 직접 전달하면 됩니다(Case-IN이 발송을 대신하지 않습니다).

만든 링크는 홈 화면의 **"사전상담 진행 현황"** 목록에 어르신 성함과 함께 표시됩니다(이 브라우저에만 저장됨). 어르신이 참여를 마치면 상태가 "검토 필요"로 바뀌고, **열기**를 누르면 바로 검토 화면으로 이동합니다. 사회복지사가 검토·수정 후 저장하면 그 사례가 이름으로 등록되고, 서버에 임시 보관된 내용과 이 목록의 항목은 함께 삭제됩니다. **삭제** 버튼으로 대기 중인 링크를 직접 정리할 수도 있습니다.

- `pre-consult.html`, `voice/remote-consult.js`: 어르신이 여는 독립 페이지 (Case-IN 본앱과 별개, IndexedDB 사용 안 함)
- `api/remote-session.js`: 결과를 3일간만 임시 보관하는 서버 저장소 API (Vercel KV/Upstash, 이후 자동 만료)
- 이 흐름에서도 음성 원본·대화 전문은 저장되지 않으며, 서버에는 구조화된 항목과 (목록 표시용) 이름만 짧게 보관됩니다.

### 배포 (Vercel)

1. 이 저장소를 Vercel 프로젝트로 연결합니다. 별도 빌드 설정이 필요 없습니다(정적 파일 + `api/` 서버리스 함수).
2. Vercel 프로젝트의 **Settings → Environment Variables**에 `OPENAI_API_KEY`를 등록합니다 (`.env.example` 참고).
3. 원격 사전상담(링크 만들기)을 쓰시려면 Vercel **Storage → Browse Storage**에서 **Upstash for Redis**(또는 Upstash)를 생성해 프로젝트에 연결하세요. (예전 "Vercel KV"는 단종되고 이 마켓플레이스 상품으로 대체되었습니다.) 연결하면 관련 환경변수가 자동으로 채워집니다.
4. 배포 후 `🎙 AI 사전상담`과 `🔗 사전상담 링크 만들기` 버튼이 정상 동작하는지 확인합니다.

OpenAI API 키는 절대 브라우저 코드에 포함되지 않으며, 서버 환경변수로만 존재합니다. 브라우저는 `/api/voice-session`이 발급한 단명(ephemeral) 토큰으로만 OpenAI Realtime API와 직접 연결합니다.
